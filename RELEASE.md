# Орбита-П — GitHub Pages

Статический сайт, готовый к размещению. Сборка и установка зависимостей не нужны.

## Публикация

1. Создайте репозиторий GitHub или используйте выбранный репозиторий сайта.
2. Загрузите **содержимое этой папки** в корень ветки `main`, включая папку `assets` и файл `.nojekyll`. Файл `index.html` должен находиться в корне репозитория, а не во вложенной папке `github-pages-release`.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Source: Deploy from a branch**, **Branch: main**, папку **/(root)** и нажмите **Save**.
5. Дождитесь успешного выполнения `pages build and deployment` во вкладке Actions. Адрес сайта появится в Settings → Pages.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Содержимое

- `index.html` — страница сайта.
- `styles.css` — оформление и адаптивные стили.
- `Marky.jpg` и пять WebP — используемые фотографии.
- `assets/` — три фоновых SVG-рисунка.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

Используются относительные ссылки: сайт работает и в корне домена, и по адресу проекта `https://USERNAME.github.io/REPOSITORY/`. Сохраняйте имена файлов и регистр букв. Пользовательский домен не настроен.
